# Still Designers — Clickable Prototype

Interactive clickable prototype for **Still Designers** (*New tools. Same curiosity.*), built with Next.js (App Router, `output: "standalone"`), Tailwind CSS, Framer Motion, and the round Allo variable typeface (`"ROND" 100`).

## Local development

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) to explore the tilted discovery grid, fly-out card modals, arrow-key card navigation, visual/excerpt-anchored discussions, weekly prompt, and role switcher.

## Deploying to Vercel

This project is ready for zero-config deployment on Vercel (and uses `output: "standalone"` in `next.config.ts` so it can also run in Docker/Node on a VPS later).
